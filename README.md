# qiita_tech_blog

Qiita投稿後の素材（本文Markdown原文・補足メモ・画像）を、記事単位で保管するリポジトリ。

## 基本運用（archive）
- `archive/YYYY/YYYY-MM-DD_slug/`
  - `article.md` : Qiitaに貼ったMarkdown原文（本文）
  - `meta.md` : URL/参照資料/概要など
  - `cpe.md` : CPE用の作業ログ・証跡
  - `assets/` : 自作図やスクショ（PNG等）

## 台帳
- ネタ帳：`archive/_index/idea_bank.md`
- CPE台帳：`archive/_index/cpe_log.md`
